# دليل تجميع تطبيق الويندوز (EXE) وتطبيق الهاتف (APK)

هذا الدليل يوضح خطوات بناء وتجميع ملف **EXE للويندوز** وتطبيق **APK للأندرويد** بدون ظهور شريط العنوان أو الرابط نهائياً، مع دعم استكشاف الطابعات والطباعة الصامتة التلقائية.

---

## 1. تطبيق الويندوز (Windows Desktop EXE)

يستخدم التطبيق **Electron.js** لتغليف النظام في نافذة سطح مكتب حقيقية:
- **إخفاء الرابط تماماً**: لا يظهر شريط عنوان (URL) أو شريط أدوات متصفح.
- **كشف الطابعات المثبتة**: يكتشف طابعات USB والشبكة عبر `window.electronAPI.getPrinters()`.
- **الطباعة الصامتة المباشرة**: طباعة فورية بدون السؤال أو إظهار نافذة تأكيد عبر `window.electronAPI.printSilent()`.
- **فتح درج النقدية**: إرسال نبضة كهربائية لدرج النقدية المتصل بالطابعة.
- **محطة طباعة مركزية للفرع**: استلام أوامر الطباعة المرسلة من هواتف الكاشير والويترز في نفس الفرع وطباعتها لحظياً وبصمت.

### خطوات التجميع (Build EXE):
1. افتح موجه الأوامر (CMD أو PowerShell) في مجلد المشروع.
2. قم بتثبيت أدوات Electron:
   ```bash
   npm install --save-dev electron electron-builder
   ```
3. لتجربة التطبيق في بيئة التطوير على الويندوز:
   ```bash
   npx electron electron/main.cjs
   ```
4. لبناء ملف **التثبيت (Setup.exe)** والنسخة المحمولة **(Portable.exe)**:
   ```bash
   npx electron-builder --config electron/electron-builder.json --win
   ```
5. ستجد ملفات الـ EXE الجاهزة داخل مجلد `release/`:
   - `Johns POS Setup x.x.x.exe` (ملف تثبيت لسطح المكتب وقائمة ابدأ)
   - `Johns POS x.x.x.exe` (نسخة Portable تعمل مباشرة بدون تثبيت)

## 2. تطبيق الهاتف (Android APK)

يستخدم التطبيق **Capacitor** لتغليف الرابط السحابي داخل تطبيق أندرويد حقيقي:
- شاشة كاملة (Fullscreen) بدون شريط متصفح أو عنوان.
- سرعة عالية وتحديث تلقائي دائم للميزات من السحابة دون الحاجة لإعادة رفع التطبيق.
- إرسال مهام الطباعة تلقائياً إلى طابور الفرع السحابي لتطبعها نسخة الويندوز مباشرة بدون أي سؤال.

### خطوات التجميع (Build APK):
1. تثبيت Capacitor في المشروع:
   ```bash
   npm install @capacitor/core @capacitor/cli @capacitor/android
   ```
2. تهيئة مشروع الأندرويد:
   ```bash
   npx cap add android
   ```
3. مزامنة الملفات والتكوين:
   ```bash
   npx cap sync
   ```
4. فتح المشروع في **Android Studio**:
   ```bash
   npx cap open android
   ```
5. في أندرويد ستوديو، اضغط على:
   `Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`
   وسينتج ملف `app-debug.apk` أو `app-release.apk` الجاهز للتثبيت على أي هاتف أو جهاز تابلت!

## 3. آلية الطباعة التلقائية بدون سؤال (Cross-Device Silent Printing)

1. **على جهاز الويندوز (جهاز الكاشير الرئيسي المتصل بالطابعات):**
   - افتح تطبيق الويندوز (EXE).
   - ادخل إلى شاشة إعدادات الطابعات من الشريط العلوي لنقاط البيع (أيقونة الطابعة 🖨️).
   - ستظهر لك قائمة الطابعات المتاحة في الويندوز تلقائياً.
   - اختر الطابعة المخصصة لكل محطة (المطبخ، المشروبات، الكاشير).
   - قم بتفعيل خيار **"محطة طباعة مركزية للفرع"**.

2. **على هاتف الكاشير أو الويتر:**
   - افتح التطبيق على الهاتف في نفس الفرع.
   - عند الضغط على "إرسال للمطبخ" أو "دفع الفاتورة"، يتم إرسال مهمة الطباعة لحظياً لسحابة النظام.
   - يلتقط تطبيق الويندوز المهمة في أجزاء من الثانية ويقوم بطباعتها فورياً على الطابعة المناسبة بدون إظهار أي نافذة أو سؤال!
